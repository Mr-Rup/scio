# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in `omnistats`, please report it privately via email to **`majumdarb107@gmail.com`** rather than opening a public issue.

We will acknowledge receipt within 48 hours and provide a remediation timeline and coordinated disclosure plan.
